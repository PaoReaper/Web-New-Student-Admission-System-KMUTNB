# ระบบรับสมัครนักศึกษาใหม่ มจพ.

เว็บไซต์ตัวอย่างสำหรับระบบรับสมัครนักศึกษาใหม่ของมหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ (KMUTNB) พัฒนาด้วย HTML, CSS และ JavaScript โดยหน้าแรกระบุการรับสมัครปีการศึกษา 2570

> **หมายเหตุ:** โปรเจกต์นี้เป็นเว็บฝั่ง Frontend สำหรับสาธิตการใช้งาน ยังไม่มี Backend หรือฐานข้อมูลกลาง ข้อมูลที่บันทึกจะอยู่ใน `localStorage` ของเบราว์เซอร์ที่ใช้งานเท่านั้น จึงไม่ควรใช้จัดเก็บข้อมูลจริงหรือข้อมูลส่วนบุคคลที่มีความอ่อนไหว

## ความสามารถ

- แสดงขั้นตอนการสมัครและหน้าข้อมูลต่าง ๆ
- ลงทะเบียนและเข้าสู่ระบบตัวอย่าง
- กรอกใบสมัครและติดตามสถานะ
- รองรับหน้าคู่มือการสมัคร ประกาศ/ผลการคัดเลือก และติดต่อสอบถาม
- บันทึกข้อมูลตัวอย่างไว้ใน `localStorage` ของเบราว์เซอร์

## เริ่มต้นใช้งาน

โปรเจกต์นี้ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

1. ดาวน์โหลดหรือ Clone repository
2. เปิด `index.html` ในเว็บเบราว์เซอร์

หรือเปิดโฟลเดอร์โปรเจกต์ด้วย Visual Studio Code แล้วใช้ส่วนขยาย **Live Server** เพื่อเปิดเว็บไซต์ผ่าน local web server

## ข้อควรทราบ

- ข้อมูลใน `localStorage` ไม่ได้ซิงก์ระหว่างอุปกรณ์หรือเบราว์เซอร์ และอาจถูกลบได้จากการล้างข้อมูลเว็บไซต์
- ระบบตัวอย่างนี้ไม่มีการยืนยันตัวตนหรือจัดเก็บข้อมูลบนเซิร์ฟเวอร์อย่างปลอดภัย
- ก่อนใช้งานจริง ควรพัฒนา Backend, ระบบฐานข้อมูล, การยืนยันตัวตน และมาตรการรักษาความปลอดภัยให้เหมาะสม
- ปีการศึกษาและรายละเอียดการรับสมัครในเว็บไซต์เป็นข้อมูลตัวอย่าง โปรดตรวจสอบและปรับปรุงให้ตรงกับประกาศจริงก่อนเผยแพร่
